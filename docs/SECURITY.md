# RSS Dashboard CN 发布前安全说明

本文是 `0.1.0` 手动自安装阶段的临时安全指引。完整的数据路径、代理、远程资源、TikHub、AI 和密钥边界见 [隐私与数据说明](PRIVACY.zh-CN.md)。

## 当前报告状态

本分支尚未创建公开仓库，也尚未公布公开安全报告渠道、邮箱或问题反馈地址。上游项目的 issues、社区和资助入口不是本分支的支持或安全报告渠道。

在公开仓库及其私密漏洞报告渠道准备完成前：

- 不要把安全问题发送到上游项目；
- 不要在任何公开页面披露凭证或个人采集数据；
- 先保留经过清洗的最小复现、插件版本、Obsidian 版本、操作系统类型和结构化错误码；
- 等本分支公布私密报告渠道后，再提交不含秘密的说明并协商后续材料传递。

本文不虚构维护者邮箱或临时公开联系地址。

## 不要提交或粘贴

- TikHub、AI、中转站或代理的 API 密钥、Token、Cookie、Authorization Header；
- 完整 `data.json`、`.rss-dashboard-data`、外部 `secrets.json` 或诊断导出；
- 原始 TikHub 响应、原始模型响应、Feed 导出或 OPML；
- 真实 X 账号、关注关键词、文章标题、正文或保存笔记；
- 知识库路径、用户目录路径、设备名称或能识别个人环境的截图；
- 未经清洗的日志、崩溃文件、录屏或测试夹具。

若怀疑密钥泄露，应先在对应服务商撤销旧密钥，再禁用插件并替换本地密钥。

## 当前安全边界

- 插件为桌面端，密钥位于知识库之外的外部文件；Unix 权限受限，Windows 依赖账户文件系统保护，不是系统加密凭证库。
- 普通采集、远程图片、favicon、代理、TikHub 与按需 AI 都可能产生第三方请求。
- 公共代理可以看到完整目标 URL；预设列表不代表隐私、安全或可用性背书。
- 设置导出不包含 API 密钥，但包含来源定义的导出仍可能带有订阅地址、账号和关键词。
- 当前代码未集成产品遥测或行为分析 SDK；第三方来源、代理和模型服务仍可能自行记录请求。

安全诊断必须先在插件中预览并由用户人工复核。即使是结构化诊断，也不要附带真实 URL、账号、关键词、标题或文件系统路径。
