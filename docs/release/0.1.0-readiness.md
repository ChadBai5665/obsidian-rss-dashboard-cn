## 版本、工作流与归属

执行：

```bash
node scripts/check-version-consistency.mjs --tag 0.1.0
node -e 'const m=require("./manifest.json"); if(m.id!=="rss-dashboard-cn"||m.name!=="RSS Dashboard CN"||m.isDesktopOnly!==true) process.exit(1)'
git log --oneline --decorate -20
rg -n 'amatya-aditya/obsidian-rss-dashboard|Aditya Amatya|MIT' README.md NOTICE.md LICENSE docs/UPSTREAM.md
```

结果：

- 版本一致性与 manifest 身份检查通过：ID 为 `rss-dashboard-cn`，名称为 `RSS Dashboard CN`，版本为 `0.1.0`，仅桌面端。
- 内部实施计划曾使用不再受支持的位置参数 `0.1.0`，脚本按严格参数策略返回 `version-check-arguments-invalid`；改用当前受支持的 `--tag 0.1.0` 后通过。没有为迁就旧计划而放宽脚本参数边界。
- 最近 20 条提交可以逐步审阅，发布加固、冒烟测试和仓库治理分别保留独立提交。
- `README.md`、`NOTICE.md`、`LICENSE` 和 `docs/UPSTREAM.md` 均保留上游项目、Aditya Amatya 和 MIT License 归属。
- 上游远程为原项目，基线为版本 `2.5.0`、提交 `048e739672337b323361cc0ce7d7bfeab7d7416b`。

## Obsidian 冒烟测试

详细记录见 [`0.1.0-smoke-test.md`](0.1.0-smoke-test.md)。

- 只复制三个发布文件即可加载；
- 简体中文首次加载、英文切换和切回中文；
- 本地合成 RSS 采集、每日索引、全量/单源刷新、失败恢复；

- AI 未配置时的明确提示；
- 禁用和卸载不产生新请求，卸载移除插件目录但保留采集数据和 Markdown；
- 一次性知识库和合成测试源已移动到系统废纸篓。
