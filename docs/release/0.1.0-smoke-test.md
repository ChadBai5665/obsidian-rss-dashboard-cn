## 存储与网络边界

- 插件安装文件和运行设置位于 `.obsidian/plugins/rss-dashboard-cn/`，其中包括设置 `data.json`；卸载后这一插件目录被移除。
- 采集记录、来源状态和保存的 Markdown 仅写入 `.rss-dashboard-data/` 和 `信息收集/`，卸载后继续保留；其余 `.obsidian/` 文件属于一次性知识库的 Obsidian 配置。
- 未配置密钥时，知识库内没有密钥文件，桌面端外部密钥文件也不存在。
- 因未创建真实密钥文件，本次无法手工观察目录 `0700`、文件 `0600` 权限；完整自动检查包含真实文件系统权限测试。
- 禁用和卸载期间，本地请求日志没有新增请求。
- 没有访问 TikHub、AI 提供商或其他付费接口。
