# RSS Dashboard CN 0.1.0 手工冒烟测试

测试日期：2026-07-24；TikHub 字幕补验：2026-07-30

测试环境：macOS、Obsidian 1.12.7、RSS Dashboard CN 0.1.0

## 结论

本地自安装、中文界面、RSS 采集、保存、刷新恢复、同日重启和卸载数据保留均通过。2026-07-30 又在一条预先指定的公开视频上完成了 TikHub YouTube 字幕补验：一次明确点击经过免费路径后使用 2 次 TikHub 字幕请求并取得非空人工英文字幕，插件预计费用约 `$0.016`。缓存重开和 Obsidian 重启均未增加本地请求账本。该结果只证明本次视频和当时服务状态，不代表 TikHub 持续可用，也不把插件估算当作服务商账单；AI 模型成功调用仍未运行。

## 存储与网络边界

- 插件安装文件和运行设置位于 `.obsidian/plugins/rss-dashboard-cn/`，其中包括设置 `data.json`；卸载后这一插件目录被移除。
- 采集记录、来源状态和保存的 Markdown 仅写入 `.rss-dashboard-data/` 和 `信息收集/`，卸载后继续保留；其余 `.obsidian/` 文件属于一次性知识库的 Obsidian 配置。
- 密钥仍只位于知识库之外的桌面端密钥文件；补验没有把密钥、请求头、服务商原始响应或完整字幕写入公开文档。
- 补验前安全安装只替换三个发布文件，并逐项确认 `data.json`、外部密钥文件、完整数据根目录和用户 Markdown 未被安装器改写。
- 补验产生的预期数据变化仅包括字幕缓存、对应条目的内容元数据、两次请求的本地账本和正常阅读器状态；既有每日采集数据与 Markdown 保留。
- 禁用和卸载期间，本地请求日志没有新增请求。字幕补验期间只运行被授权的两次 TikHub 字幕请求；未访问 AI 模型服务。
